## Featured work

### [BidOu: real-time auction platform](https://github.com/IpfaniMuleya/bidou-showcase)
`Java 21` `Spring Boot 4` `React` `PostgreSQL` `Redis` `WebSocket` `Docker`

- Four auction formats (proxy, Dutch, Vickrey, candle) with live bidding over WebSocket.
- Found a race between a Redis lock and a database commit, reproduced it with a
  40-bidder Testcontainers test, and fixed it.
- Security: JWT auth, TOTP two-factor for admins, an admin audit log, role-based access.
- Patched the Java4Shell JVM flaw (CVE-2026-114938) and cut known dependency
  vulnerabilities from 123 to 0 by upgrading to Spring Boot 4.
- [Case study, architecture and a runnable bidding engine →](https://github.com/IpfaniMuleya/bidou-showcase)
